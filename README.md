# Chloid
Chloid is a 4 track algorithmic sequencer built on the [DROID platform](https://shop.dermannmitdermaschine.de/pages/droid-universal-cv-processor). It is heavily inspired by the workings of the [CLANK Chaos](https://www.clank.eu/chaos) and is designed to be a more hands-on version of it  (hence the name **Ch**aos **l**ike dr**oid**). I'd also like to mention the [SuperGrids](https://github.com/jpgsloan/supergrids) here as I  reused some of this very nice patch for my purposes. 

## What you need to use it
The current setup is designed to have a minimal footprint in your case and consists of the following DROID elements

- DROID MASTER 18
- P2B8 controller
- B32 controller
- E4 controller

## What it does
In essence, this patch implements a 4 track gate and CV sequencer with the ability to control gates and CV independent from each other. This is afforded by running two independent algoquencers per track (one for gates and one for CV). These two can be controlled and timed independent from each other meaning that you can set independent clock divisions, clock delays or grooves as well as all other parameters for the any of them. Additionally track 1 and 2 output an envelope triggered by the set steps. This allows to build a VCA based groove or any other parameter you want to control with it. Track 1 is designed to work as a sidechain envelope so by default it is inverted. Track 2 outputs the envelope as is. Finally you can decide whether you want to use the whole thing as a master clock or run it synced to a midi clock.

## The interface
To explain how to control this beast of a patch let us first have a look at the setup and all the assigned functions to the buttons, knobs and jacks.

![](https://github.com/dmalzl/chloid/blob/reui/chloid_interface.png)

The center of the UI is the B32 controller which implements most of the different selectors used to navigate the encoder pages etc. The P2B8 implements mode selectors and global manipulators as well as the play / pause button etc. The 4 gate jacks of the MASTER18 output the generated gates of the 4 gate algoquencers. The first column of output jacks output the random voltages generated by the 4 corresponding CV algoquencers. O2 and O4 output the envelopes associated with track 1 and 2 algoquencers respectively and O6 and O8 output a RUN gate and a 24PPQ clock signal respectively. Additionally, MIDI1 in is reserved for MIDI sync, its out is reserved for MIDI thru and MIDI2 out  outputs MIDI info from the MASTER18 internals (currently this is just RUN and clock to sync MIDI devices to the DROID)

## Globals
Apart from the obvious function of the PLAY button and P1 to change the tempo from 30 - 240 BPM, there are a couple of things that you can do globally. The first one would be that if you hold down the PLAY button for longer than 1.5 seconds you enter the clock selection menu, which lets you select whether to sync the MASTER18 to an external MIDI clock or run off it's internal clock. This is done by holding the PLAY button and pressing the RESET ALL button. This will toggle the led of the RESET ALL button, which now indicates that your systems is currently synced to the clock received at MIDI1 in. Furthermore, when still holding the PLAY button down you also have access to a global clock delay via P2 of the P2B8. This allows you to offset the clock a bit to adjust for any timing differences between you synced devices and the DROID. Removing your finger from the button will automatically get you back to the default functions. Here the led of the RESET ALL button will stay lit half of its intensity to indicate that MIDI is synced.

Next would be the RESET ALL, CLEAR ALL and REROLL ALL buttons which do exactly what their names suggest, reset all the algoquencers steps to the first one, clear all the algoquencers and parameters to their default state (handy if you want to start over from a blank slate) and reroll the patterns of all algoquencers. However, to avoid accidental use of these buttons all are implemented as `longpress` meaning that you need to press them at least two seconds for them to have an effect.

The function of the mode selectors is also self explanatory and will get even clearer in the modes section below. So I don't elaborate on them here more than saying they toggle the selectors for the different algoquencers and their parameters.

## The modes
The Chloid implements two main modes to get access to the controls of the GATE and CV algoquencers for each track. Each mode comes with a set of parameters  that are accessible via the B32 page selectors and manipulated via the E4 encoders. Additionally, you can always switch to an ALT mode which gives you access to the alternate pattern of the currently selected algoquencer or to a MUTE mode which allows you to mute any number of tracks (note this only mutes the gate and trigger outputs of the algoquencers so all CV related things are still output as is. This is especially important for the envelopes as we usually don't want to stop sidechaining etc. when the kick is muted. At least I don't).
