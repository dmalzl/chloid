# Chloid
Chloid is a 4 track algorithmic sequencer built on the [DROID platform](https://shop.dermannmitdermaschine.de/pages/droid-universal-cv-processor). It is heavily inspired by the workings of the [CLANK Chaos](https://www.clank.eu/chaos) and is designed
to be a more hands-on version of it (hence the name **Ch**aos **l**ike dr**oid**). I'd also like to mention the [SuperGrids](https://github.com/jpgsloan/supergrids) here
as I reused some of this very nice patch for my purposes. 

## What you need to use it
The current setup is designed to have a minimal footprint in your case and consists of the following DROID elements

- DROID MASTER 18
- P2B8 controller
- B32 controller
- E4 controller
